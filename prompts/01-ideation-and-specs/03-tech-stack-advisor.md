# 🛠️ Prompt 1.3: Cố Vấn Công Nghệ (Tech Stack Advisor Dành Cho Người Mới)

> **Mục tiêu**: Giúp bạn chọn đúng ngôn ngữ, framework và cơ sở dữ liệu phù hợp với trình độ người mới (học sinh cấp 3, sinh viên năm nhất), tránh việc chọn công nghệ quá phức tạp khiến dự án bị bỏ dở giữa chừng.

---

## 📝 Nội Dung Prompt

```text
[BỐI CẢNH]
Tôi đang muốn tự tay xây dựng một website: [Mô tả website của bạn, ví dụ: Web blog cá nhân / Web quản lý chi tiêu học sinh / Web bán áo đồng phục lớp].
Trình độ hiện tại của tôi: [Ví dụ: Chưa biết gì về code / Mới biết chút ít HTML CSS / Đã học cơ bản Python].
Thời gian tôi muốn hoàn thành bản chạy được (MVP): [Ví dụ: Trong 3 ngày / 1 tuần / 2 tuần].
Mục tiêu: Miễn phí hosting tối đa, dễ cài đặt nhất, AI hỗ trợ sinh code chuẩn nhất.

[VAI TRÒ]
Bạn là Kỹ sư Trưởng (Tech Lead) và là Người hướng dẫn lập trình viên mới vào nghề. Bạn luôn ưu tiên giải pháp đơn giản, hiệu quả, tiết kiệm chi phí và dễ học nhất.

[NHIỆM VỤ CỦA BẠN]
Hãy tư vấn cho tôi 2 lựa chọn công nghệ (Tech Stack):

Lựa chọn 1: Dành cho người cực kỳ mới bắt đầu (Mì ăn liền, làm nhanh nhất trong 1-2 ngày)
- Frontend: Công nghệ gì? (Ví dụ: Vanilla HTML/CSS/JS + Tailwind CDN).
- Backend & Database: Công nghệ gì? (Ví dụ: Supabase BaaS hoặc Firebase hoặc LocalStorage).
- Nơi lưu trữ (Hosting): Miễn phí ở đâu? (Ví dụ: Vercel, GitHub Pages).
- Ưu & Nhược điểm.

Lựa chọn 2: Dành cho người muốn học bài bản để đi làm hoặc thi học sinh giỏi Tin học / Dự án trường
- Frontend: (Ví dụ: React / Next.js / Vite).
- Backend: (Ví dụ: Node.js Express / Python FastAPI).
- Database: (Ví dụ: PostgreSQL / Supabase / SQLite).
- Ưu & Nhược điểm.

Kèm theo: Lời khuyên nên bắt đầu cài đặt những phần mềm gì lên máy tính theo thứ tự từ 1 đến 3.
```
