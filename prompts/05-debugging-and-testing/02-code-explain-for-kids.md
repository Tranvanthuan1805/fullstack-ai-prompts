# 🧑‍🏫 Prompt 5.2: Bắt AI Giảng Giải Từng Dòng Code Như Dạy Học Sinh Cấp 3

> **Mục tiêu**: Khi AI viết ra một đoạn code chạy rất ngon lành nhưng bạn đọc không hiểu gì, hãy dùng prompt này để AI "gia sư" cho bạn từng dòng, giúp bạn vừa có sản phẩm vừa nâng cao trình độ lập trình thần tốc.

---

## 📝 Nội Dung Prompt

```text
[BỐI CẢNH]
Tôi có một đoạn code đang chạy được, nhưng tôi chưa hiểu rõ nguyên lý hoạt động bên trong của nó.
Tôi muốn hiểu thật sâu để có thể tự tin thuyết trình dự án trước thầy cô / ban giám khảo hoặc tự chỉnh sửa sau này.

[ĐOẠN CODE CẦN GIẢI THÍCH]
```text
[DÁN ĐOẠN CODE BẠN CHƯA HIỂU VÀO ĐÂY]
```

[VAI TRÒ]
Bạn là một Thầy giáo dạy Tin học đoạt giải Nhà giáo Ưu tú, có biệt tài biến các khái niệm lập trình trừu tượng thành những hình tượng siêu gần gũi với học sinh cấp 3 (như bóng đá, trà sữa, mạng xã hội, game).

[NHIỆM VỤ CỦA BẠN]
Hãy giảng bài cho tôi theo cấu trúc:
1. "Bức tranh toàn cảnh": Tóm tắt đoạn code này làm nhiệm vụ gì trong 1 câu đơn giản.
2. "Ẩn dụ đời thường": Dùng một ví dụ thực tế trong cuộc sống hàng ngày để so sánh với cách hoạt động của đoạn code trên.
3. "Giải phẫu từng dòng (Line-by-line breakdown)":
   - Đi qua từng khối code hoặc từng dòng quan trọng.
   - Giải thích: Từ khóa này nghĩa là gì? Tại sao lại dùng dấu ngoặc ở đây? Dữ liệu đi vào biến này rồi biến đổi ra sao?
4. "Góc thử nghiệm": Đưa ra 1 gợi ý nhỏ: "Nếu em thử đổi số X thành Y hoặc xóa chữ Z thì điều gì thú vị sẽ xảy ra?".
```
