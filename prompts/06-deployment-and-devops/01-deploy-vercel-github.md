# 🚀 Prompt 6.1: Đưa Website Lên Internet Miễn Phí Qua Vercel & GitHub (Deploy Guide)

> **Mục tiêu**: Hướng dẫn AI chỉ dẫn bạn từng cú nhấp chuột để đẩy code từ máy tính lên GitHub, sau đó kết nối với Vercel để nhận đường link website công khai dạng `https://ten-du-an-cua-ban.vercel.app` gửi cho bạn bè, thầy cô xem ngay.

---

## 📝 Nội Dung Prompt

```text
[BỐI CẢNH]
Tôi vừa code xong một website trên máy tính cá nhân.
Thư mục dự án của tôi bao gồm: [Mô tả file, ví dụ: 1 file index.html / Hoặc project React Next.js / Hoặc Frontend và Backend].
Tôi muốn đưa website này lên mạng Internet hoàn toàn miễn phí, có chứng chỉ bảo mật HTTPS (hình ổ khóa xanh) và có tên miền để gửi cho bạn bè truy cập thử.

[VAI TRÒ]
Bạn là Kỹ sư Vận hành Đám mây (DevOps Engineer) tận tâm, hướng dẫn từng bước chi tiết "cầm tay chỉ việc" như đang ngồi cạnh chỉ dẫn người mới.

[NHIỆM VỤ CỦA BẠN]
Hãy chia lộ trình đưa web lên mạng thành 3 phần siêu dễ hiểu:

Phần 1: Đẩy mã nguồn từ máy lên GitHub
- Hướng dẫn các câu lệnh Git cơ bản: `git init`, `git add .`, `git commit -m "first commit"`.
- Cách tạo repository mới trên trang github.com và gắn link remote: `git remote add origin ...`, `git push -u origin main`.
- (Nếu người dùng không thích gõ lệnh terminal, hãy chỉ cách dùng phần mềm giao diện GitHub Desktop).

Phần 2: Kết nối Vercel và Xuất bản website
- Cách đăng nhập Vercel bằng tài khoản GitHub (1 cú click).
- Cách bấm nút "Add New Project" -> Chọn Repository vừa tạo -> Bấm "Deploy".
- Chờ 30 giây để Vercel tự động dựng website và nhận đường link chính thức.

Phần 3: Cập nhật website sau này
- Sau này khi tôi sửa code trên máy tính, làm sao để Vercel tự động cập nhật bản mới nhất lên mạng mà không cần làm lại từ đầu?
```
